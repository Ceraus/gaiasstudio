# ClearPlan Roadmap

## Layout System

- Keep all authenticated routes inside the single `AppShell`.
- Do not add page-local application headers, duplicate nav rows, or standalone sidebars.
- Route future workspace sections through the shared dark sidebar.

## Plans

- Replace the PDF placeholder with a real PDF renderer.
- Add persisted plan versions, markups, layers, and measurements.
- Keep pin coordinates stored as percentages.

## Data

- Replace mock data with typed service calls.
- Move local object URLs to persistent file/media storage.
- Add auth and organization switching when backend work begins.
